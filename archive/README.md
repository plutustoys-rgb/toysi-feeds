# archive/ — холодний архів повної історії

Два рівні запису (рішення власника 2026-08-21):

- **Гарячий** — `CODE_LOG.md`, код-коментарі, памʼять: **результат + один нюанс** (пастка / чому саме так). Коротко, читається щоразу, тримає контекст малим.
- **Холодний (ця папка)** — **повна історія**: ітерації, хибні спроби, «тривали X → впало на Y → тому Z», повні таймлайни інцидентів. Лежить окремо, контекст не роздуває, але **дістається за потреби**.

## Навіщо
Не втрачати глибоку історію (іноді треба — «а ми це вже пробували?»), але й не змушувати кожну сесію перечитувати сотні хибних ітерацій до результату. Гаряче — сигнал; холодне — доказова база.

## Іменування
`YYYY-MM-DD_тема.md` — напр. `2026-08-21_rz-marking-reliability.md`. Одна тема/інцидент/день — один файл.

## Що сюди
- трейл проб-і-помилок і **тупики** («пробували outbox-дренер — відкинули, бо…» / «samovyviz-carrier — Toysi відмовився») — щоб НЕ повторювати;
- повні таймлайни інцидентів (діагностика по кроках);
- сирі виводи/дампи, що були потрібні для рішення.

## Як дістати
- `python recall.py "тема"` → серед іншого показує **вказівники на архів** (файли, що метчать тему);
- відкрити конкретний файл для повної саги; або `grep -ri "<тема>" archive/`.

## Що НЕ сюди
Секрети/токени/cost/margin — ніколи (правило витоку). Архів у git — публічно версіонований.
