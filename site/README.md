# PlutusToys — статичний магазин (`plutustoys.com.ua`)

Власний сайт-магазин, що генерується з живого каталогу Toysi **без CMS/платформи**
(рішення брифу — сенс сайту: прибрати комісію маркетплейсу, а не платити ще одній платформі).

## Збірка

```bash
cd rozetka_agent
python site/build_site.py          # повний каталог
LIMIT=120 python site/build_site.py # швидкий демо-зріз
SITE_GA4_ID=G-XXXXXXXXXX SITE_META_PIXEL_ID=<цифри> python site/build_site.py # аналітика (без ID — без сніпетів; див. deploy/DEPLOY_SITE.md §5б)
SITE_LIQPAY_LIVE=1 python site/build_site.py # лише коли LiqPay бойовий: показує «оплата карткою» (футер, кошик, оферта); без прапорця сайт обіцяє лише накладений платіж
```

Генерує у `site/`: `index.html` (головна «Новинки» + категорії), `catalog.html`,
`category-<slug>.html` на кожну категорію, `product-<id>.html` на кожен товар,
`cart.html` (кошик + checkout), `index.json` (індекс клієнтського пошуку).
Ці файли — білд-вихід (у `.gitignore`); у репо лишаються **генератор + ассети**.

## Що в репо (комітимо)

- `build_site.py` — генератор.
- `assets/styles.css` — спільна палітра/компоненти (тепла палітра з дизайну SMM).
  Підключення з `?v=<sha1 вмісту, 8 hex>` (`build_site.asset_url`): /assets/ кешується браузером на добу, версія в URL змінюється лише з вмістом — фікс доїжджає до тих, хто вже був на сайті.
- `assets/app.js` — кошик (localStorage), лічильник, пошуковий оверлей, checkout.
- `category_texts.json` — вступні тексти категорій від SEO: `{"<slug>": "абзац 1\n\nабзац 2"}`. Абзаци розділяти ЛІТЕРАЛЬНИМ `\n\n` усередині рядка JSON (НЕ клавішею Enter — це невалідний JSON). slug = ім'я файлу категорії без `category-` і `.html` (для однойменних категорій — `foo-2`). Показується під H1 лише на 1-й сторінці, HTML екранується; нема slug — блоку нема. Збірка ГОЛОСНО (stderr) каже, якщо файл не прочитався (BOM читається нормально), значення не рядок або slug не збігся зі сторінкою.
- `product_texts.json` — тексти карток товарів від SEO (внутрішня перелінковка 12.10): `{"<toysi_id>": "абзац 1\n\nабзац 2"}`, id — лише цифри, значення — plain text (HTML екранується; `\n\n` — абзаци, літерально, не Enter). Показується блоком `div.prod-text` під описом Toysi, перед його характеристиками, на картці в наявності й на OOS-сторінці; нема id — блоку нема. Збірка ГОЛОСНО (stderr): файл не прочитався (BOM читається нормально), значення не рядок, id не з цифр, текст >900 символів, id без картки в збірці.
- `category_related.json` — «Схожі категорії» від SEO: `{"related": {"<slug>": ["<slug>", …]}}` (slug = ім'я файлу без `category-` і `.html`; ключ `description` ігнорується). До 6 посилань `nav.relcats` на 1-й сторінці категорії; показуються лише slug-и, сторінка яких є в збірці, без самої категорії; пагінація блок не дублює. Збірка ГОЛОСНО каже про непрочитаний/некоректний файл і про slug-и без сторінки.
- «Схожі товари» (картка, `section.related`) — без файлу: до 6 товарів у наявності з тієї ж категорії, найближчих за ціною (відстань, потім id); для «Уцінки»/«Уценки» блоку нема.
- Пагінація (`_pager`): `1 … n-2 n-1 n n+1 n+2 … остання` + «орієнтири» (початки великих блоків, середніх блоків поточного великого, усі сторінки поточного середнього) — з 1-ї сторінки до будь-якої ≤3 кліків; ≤7 сторінок — усі номери. rel prev/next і canonical не змінюються.

## Ціноутворення

Ціна вітрини = `competitor_pricing.toysi_discounted_price(it) × 1.5` (без комісії маркетплейсу).
Каталог — увесь in-stock Toysi з фото (без відсікань за ціною чи категорією). Націнка як у EVA-фіді; жодних зв'язків із маркетплейсами.
